# 🛒 Ecommerce Website

A full-stack ecommerce web application with authentication, cart system, and secure payment integration.


## 🚀 Features
- User authentication (Signup/Login)
- Product listing & cart system
- Order history
- Secure checkout
- Payment integration using Razorpay
- Payment verification for security

## 🛠 Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Database: MongoDB
- Deployment: Netlify (Frontend), Render (Backend)
